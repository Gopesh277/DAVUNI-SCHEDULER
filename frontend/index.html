No teacher will ever be scheduled for more than this many periods in an unbroken run on the same day. A run that crosses the lunch break doesn't count as unbroken.

Daily load by faculty position

Maximum periods per day allowed for each register category — e.g. senior faculty typically carry a lighter daily teaching load than contractual faculty. Matched against each course row's "Register" value on the Manage data tab (case-insensitive). Anything not listed uses the fallback cap.
